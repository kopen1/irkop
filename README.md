# IRKOP Standalone Web Platform

Standalone Next.js (App Router) deployed to **Cloudflare Pages**, backed by a
**Cloudflare Worker** API and **Cloudflare D1** database.

- **Public domain:** `https://irkop.pages.dev` (Cloudflare auto-assigns this from project name `irkop`)
- **PRD mentions:** `irkop.page.dev` — that's a custom domain; attach it later in Pages dashboard
- **Architecture:** Standalone — NOT connected to any Irkop Cell backend/auth/DB
- **Stack:** Next.js 14 + React 18 · TypeScript · Cloudflare Pages · Cloudflare Workers · Cloudflare D1
